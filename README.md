# Фото-студия «Ракурс» — веб-приложение для заказа фотосессий

Учебный проект, выполненный в рамках производственной практики по
профессиональному модулю **ПМ.05 «Проектирование и разработка информационных
систем»** (специальность 09.02.07). Предметная область — **фото-студия**
(портфолио работ + онлайн-заказ фотосессии).

Реализован полный поток: **регистрация → авторизация → работа с сущностями**
(личный кабинет клиента + панель администратора), адаптивный дизайн под
мобильный экран 390×844 и набор функций из модулей 1–3 индивидуального
задания.

---

## 1. Стек технологий

| Слой       | Технология                                   |
|------------|-----------------------------------------------|
| Backend    | Python 3.10+, Flask 3                          |
| БД         | SQLite (файл `app/photostudio.db`, создаётся автоматически). SQL-скрипт схемы в MySQL-совместимом синтаксисе — `docs/schema.sql` |
| Frontend   | HTML5, CSS3 (Flexbox/Grid, медиазапросы), Vanilla JS (без фреймворков) |
| Авторизация | Flask session + `werkzeug.security` (хэширование паролей) |

## 2. Сущности базы данных

### 2.1 `users` — пользователи (клиенты и администратор)

| Поле            | Тип                          | Описание                         |
|------------------|-------------------------------|-----------------------------------|
| id               | INT, PK                       | Идентификатор                     |
| full_name        | VARCHAR(150)                  | ФИО                                |
| login            | VARCHAR(50), UNIQUE           | Логин для входа                   |
| password_hash    | VARCHAR(255)                  | Хэш пароля                        |
| phone            | VARCHAR(20)                   | Телефон                           |
| email            | VARCHAR(100), UNIQUE          | Email                              |
| role             | ENUM('client','admin')        | Роль пользователя                 |
| created_at       | DATETIME                      | Дата регистрации                  |

### 2.2 `photoshoot_types` — справочник вариантов фотосессий

| Поле              | Тип            | Описание                          |
|--------------------|-----------------|-------------------------------------|
| id                 | INT, PK         | Идентификатор                      |
| name               | VARCHAR(100)    | Название варианта                  |
| description        | TEXT            | Описание                            |
| price              | DECIMAL(10,2)   | Стоимость, ₽                        |
| duration_minutes   | INT             | Длительность, мин                   |

### 2.3 `bookings` — заявки клиентов на фотосессию

| Поле                | Тип                                                   | Описание                     |
|----------------------|--------------------------------------------------------|--------------------------------|
| id                   | INT, PK                                                | Идентификатор заявки          |
| user_id              | INT, FK → users.id                                     | Клиент                        |
| photoshoot_type_id   | INT, FK → photoshoot_types.id                          | Вариант фотосессии            |
| booking_date         | DATE                                                    | Дата съёмки                   |
| booking_time         | TIME                                                    | Время съёмки                  |
| payment_method       | ENUM('cash','card','online')                           | Способ оплаты                  |
| status               | ENUM('new','confirmed','completed','cancelled')        | Статус заявки (4 статуса)      |
| comment              | TEXT                                                    | Комментарий клиента            |
| created_at           | DATETIME                                                | Дата создания заявки           |

**Связи:** `users (1) — (N) bookings`, `photoshoot_types (1) — (N) bookings`.

ER-диаграмма: `docs/er_diagram.png`. SQL-скрипт создания схемы (MySQL):
`docs/schema.sql`.

## 3. Сценарии использования

1. **Гость** открывает главную страницу, видит портфолио (слайдер из 4 фото)
   и список вариантов фотосессий.
2. **Регистрация**: гость заполняет форму (ФИО, логин, телефон, email,
   пароль) → сервер проверяет формат каждого поля и уникальность логина/email
   → при успехе запись добавляется в `users`, пользователь перенаправляется
   на страницу входа.
3. **Авторизация**: пользователь вводит логин/пароль → сервер проверяет
   существование пользователя и совпадение пароля, при ошибке показывает
   понятное сообщение и позволяет вернуться к регистрации.
4. **Личный кабинет клиента** (`/cabinet`): список собственных заявок +
   форма создания новой заявки (вариант съёмки, дата, время, способ оплаты,
   комментарий) с валидацией на клиенте и сервере.
5. **Панель администратора** (`/admin`, доступна только роли `admin`):
   список всех заявок всех клиентов, фильтр по статусу, пагинация, смена
   статуса заявки (Новая → Подтверждена → Выполнена / Отменена) без
   перезагрузки страницы (AJAX) с уведомлением-тостом.

Демо-доступ администратора создаётся автоматически при первом запуске:
`login: admin / password: Admin12345`.

## 4. Модули задания и их реализация

**Модуль 1. Проектирование БД** — таблицы `users`, `photoshoot_types`,
`bookings`, ER-диаграмма (`docs/er_diagram.png`), SQL-скрипт
(`docs/schema.sql`), регистрация/авторизация с валидацией, личный кабинет и
форма заявки, админ-панель со списком заявок и сменой статуса.

**Модуль 2. Дизайн** — адаптивная вёрстка (мобильный экран 390×844 как
базовый, брейкпоинты 480px/900px для планшета и десктопа), слайдер портфолио
из 4 изображений (автопрокрутка 3 с, кнопки «вперёд/назад», точки-навигация,
пауза при наведении), оптимизация изображений (см. `docs/optimization_demo`,
экономия ≈90% веса без потери качества), UI-гайд — см. раздел 5, доступность
(фокус-состояния, alt-тексты, контрастные статус-бейджи).

**Модуль 3. Функционал** — доработанная схема БД под все сценарии
(индексы по `status`/`user_id`/`booking_date`, внешние ключи, ограничения
`CHECK`), интеграция фронта и бэка (формы создают/читают/фильтруют записи в
реальном времени), микроанимации (hover-эффекты кнопок и карточек, toast-
уведомления, плавные переходы бургер-меню и слайдера), проверенная
адаптивность на мобильном экране.

## 5. UI-гайд (кратко)

- **Цвета:** `#FF7A45` (акцент), `#22223B` (тёмный / шапка), `#FFF8F3`
  (фон), статусы — `#607D8B` / `#1E88E5` / `#2E7D32` / `#C62828`.
- **Шрифт:** Segoe UI / system-ui, заголовки — полужирный/жирный.
- **Сетка:** Flexbox + CSS Grid, мобильный экран 390×844 как база,
  расширение сетки на 480px и 900px.
- **Компоненты:** скруглённые карточки (radius 12px), мягкие тени,
  статус-бейджи с цветовой кодировкой, toast-уведомления снизу экрана.

## 6. Установка и запуск

```bash
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # Linux/Mac

pip install -r requirements.txt
python run.py
```

Приложение будет доступно на `http://127.0.0.1:5000/`.
База данных SQLite и справочник вариантов фотосессий создаются автоматически
при первом запуске (см. `app/database.py`).
